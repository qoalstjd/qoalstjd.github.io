Naming

접두사

  • 배너 / Hero: bnr_
  • 카드 / 썸네일: card_
  • 아이콘 / 심볼: ico_
  • 배경 / 배경패턴: bg_
  • 상품 / 제품: prd_
  • 프로필 / 인물: pf_
  • 로고 / 브랜드: logo_
  • 버튼 / UI 요소: btn_
  • 일러스트 / 그림: ill_

반응형/적응형 이미지

  • 화면 크기에 따라 다른 해상도 이미지를 로드 (srcset, sizes)
  • 모바일에서는 가벼운 이미지만, PC에서는 고해상도

레이아웃과 콘텐츠 흐름에 맞춘 구조

  • 섹션별로 이미지 위치, 비율, 비주얼 강조 방식 재조정
  • 스크롤이나 CTA 흐름을 방해하지 않도록 배치

파일 구조 정리

  • img/hero/, img/card/, img/thumbnail/처럼 용도별 폴더
  • 이름 규칙과 형식 통일 (jpg/png/webp)

Lazy Load 적용

  • 화면에 나타날 때만 이미지 로드 → 초기 로딩 속도 개선
  • SVG / 플레이스홀더 활용
  • 아이콘이나 배너 일부는 SVG 사용 → 용량 절약, 색상 제어 가능
  • 플레이스홀더로 로딩 느낌 제공 가능

접근성 고려

  • alt 텍스트 필수
  • 의미 있는 이미지와 장식용 이미지 구분
  • 1. 배너/프로모션 (bnr_)
  • 목적: 시각적 강조 + 클릭 유도
  • alt 예시
  • alt="2025년 연말 이벤트 배너 - 최대 50% 할인"
  • alt="신제품 출시 프로모션 배너"
  • 팁: 배너의 핵심 메시지만 담고, "배너 이미지" 같은 불필요한 말은 생략.
  • 2. 카드/상품 (card_)
  • 목적: 콘텐츠 요약, 상품/정보 표시
  • alt 예시
  • alt="프리미엄 블루투스 이어폰 제품 카드"
  • alt="서울 여행 패키지 소개 카드"
  • 팁: 상품명이나 핵심 정보 중심. 링크 텍스트와 중복되지 않게.
  • 3. 이벤트 (evt_thumb, evt_detail)
  • 썸네일: alt="이벤트 제목 간단 설명"
  • 상세: alt="이벤트 제목과 상세 정보"
  • 팁: 썸네일은 간결, 상세는 충분히 설명.
  • 4. 장식용/UI 요소 (ico_, bg_)
  • 목적: 순수 장식, 정보 전달 없음
  • alt: 빈 문자열 alt="" 또는 CSS로 background 처리
  • 팁: 스크린리더에 읽히지 않게 하여 혼동 방지.
  • 5. 일반 규칙
  • 중복 금지: 동일 페이지에 alt 동일하게 반복 X
  • 구체적: “사진”보다는 “서울 타워 야경”처럼 구체적으로
  • 간결: 125자 이내 권장
  • 맥락 고려: 이미지가 전달할 정보를 반영
