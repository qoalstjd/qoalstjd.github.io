이 프로젝트는 펜션 홍보부터 예약까지 한 번에 이어지는 흐름을 목표로 진행했다. 기획, 구조 설계, 화면 구성, 기능 구현까지 전 과정을 직접 작업했다.

프로젝트 개요

01. 목적

  • 펜션 홍보를 통한 고객 유치
  • 이용자가 필요한 정보를 빠르게 확인
  • 예약까지 자연스럽게 이어지는 사용자 흐름 구성

02. 개발 환경 및 사용 기술

  • HTML, CSS, JavaScript 기반 구현
  • 외부 프레임워크 없이 순수 JS로 SPA 구조 구성
  • History API를 활용한 페이지 전환 처리
  • 공통 레이아웃과 콘텐츠 영역 분리

03. 주요 기능

  • 예약 시스템 구축
  • 게시글 관리용 Admin 페이지 제공
  • DB 연동을 통한 데이터 관리

기획 및 구조 설계

개발에 앞서 전체 페이지 흐름과 필요한 콘텐츠를 먼저 정리했다. 기능을 무작정 늘리기보다는, 실제 사용자에게 꼭 필요한 요소 위주로 구성하는 데 집중했다.

01. 정보 구조(IA) 설계

  • 필요한 정보만 메뉴로 구성
  • 메뉴 깊이를 최소화해 사용자가 헷갈리지 않도록 설계
  • 공통 레이아웃 유지, 콘텐츠 영역만 페이지별로 분리

02. 페이지 구성 전략

  • 메인 페이지에서 핵심 정보 요약 제공
  • 상세 페이지에서 정보 집중 노출
  • 반복 요소는 공통 컴포넌트로 관리

UI / UX 설계

디자인보다 사용성을 우선으로 두고 화면을 구성했다. 사용자가 별도의 설명 없이도 자연스럽게 흐름을 따라갈 수 있도록 직관적인 구조를 유지하는 데 집중했다.

01. 레이아웃 기준

  • 모바일과 PC 모두 대응 가능한 반응형 구조
  • 읽기 편한 여백과 단순한 정보 배치
  • 반복되는 UI 요소는 동일한 규칙으로 사용

02. 사용성 개선 포인트

  • 예약 버튼 등 주요 액션 요소 강조
  • 스크롤만으로 주요 정보 확인 가능
  • 불필요한 클릭 최소화

구현 과정

기획 단계에서 정리한 구조를 기준으로 HTML과 CSS를 작성하고, JavaScript로 동작을 구현했다. 유지보수를 고려해 코드 구조는 최대한 단순하게 유지했다.

01. 마크업 전략

  • 의미에 맞는 시맨틱 태그 사용
  • 접근성을 고려한 기본 구조 유지

02. 스타일 및 구조 관리

  • 공통 스타일과 페이지별 스타일 분리
  • 일관된 클래스 네이밍 규칙 사용
  • 공통 CSS 중심으로 구성

이번 작업을 통해 단순히 화면을 구현하는 것보다 구조와 사용자 흐름을 먼저 설계하는 것이 얼마나 중요한지 다시 한 번 느낄 수 있었다. 이후에는 사용자 반응을 기반으로 한 개선도 진행해볼 계획이다.
