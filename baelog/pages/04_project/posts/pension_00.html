프로젝트 개요

본 프로젝트는 웹 사이트 구축 전반을 경험하고, 실제 사용성을 고려한 구조 설계와 구현을 목표로 진행했다. 기획부터 화면 구성, 퍼블리싱까지 전 과정을 직접 담당했다.

프로젝트 목적

  • 콘텐츠 중심의 명확한 정보 전달
  • 유지보수가 쉬운 구조 설계
  • 확장 가능한 페이지 구성

기획 및 구조 설계

개발에 앞서 전체 콘텐츠 흐름과 페이지 간 관계를 먼저 정리했다. 불필요한 기능은 배제하고 핵심 기능 위주로 구성했다.

정보 구조(IA) 설계

  • 페이지 역할에 따른 메뉴 분리
  • 사용자 동선을 고려한 메뉴 깊이 제한
  • 공통 레이아웃과 개별 콘텐츠 영역 분리

페이지 구성 전략

  • 메인 페이지에서 핵심 콘텐츠 요약 제공
  • 상세 페이지에서 정보 집중 제공
  • 반복 요소는 컴포넌트 단위로 관리

UI / UX 설계

디자인은 시각적 요소보다 사용자의 행동 흐름을 우선으로 고려했다. 직관적인 인터랙션과 일관된 레이아웃을 유지하는 데 집중했다.

레이아웃 기준

  • 모바일 우선 설계(Mobile First)
  • 콘텐츠 가독성을 고려한 여백 설정
  • 반복 사용되는 UI 요소의 규칙화

사용성 개선 포인트

  • 중요 버튼의 시각적 강조
  • 스크롤만으로 주요 정보 접근 가능
  • 불필요한 클릭 최소화

구현 과정

기획 단계에서 정의한 구조를 기준으로 마크업과 스타일을 구현했다. 코드의 재사용성과 가독성을 우선으로 작업했다.

마크업 전략

  • 의미에 맞는 시맨틱 태그 사용
  • 콘텐츠 영역과 UI 영역 분리
  • 접근성을 고려한 구조 유지

스타일 및 구조 관리

  • 공통 스타일과 페이지별 스타일 분리
  • 클래스 네이밍 규칙 통일
  • 확장 가능한 CSS 구조 유지

정리 및 회고

이번 웹 구축 작업을 통해 단순한 화면 구현을 넘어 구조와 흐름의 중요성을 다시 한 번 느낄 수 있었다. 이후 프로젝트에서는 사용자 데이터 기반 개선을 목표로 한다.
