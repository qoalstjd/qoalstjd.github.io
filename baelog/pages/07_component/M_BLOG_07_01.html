List

개요

List 컴포넌트는 텍스트 기반 정보를 구조적으로 전달하기 위한 UI 요소입니다. 이를 통해 콘텐츠의 가독성과 정보 흐름을 개선할 수 있습니다.
단순한 항목 나열이 아니라, 정보의 관계(순서, 계층, 그룹)를 시각적으로 표현하여 사용자가 콘텐츠를 빠르게 이해하도록 돕습니다.

핵심 특징

  • 정보를 구조화하여 명확하게 전달
  • 계층, 순서, 그룹 등의 관계 표현 가능
  • 텍스트 기반 콘텐츠에 최적화
  • 단일 목적이 아닌 정보 구조 중심 컴포넌트

구조 유형

  • Unordered List (ul) - 순서 없는 일반 정보 나열
  • Ordered List (ol) - 단계/순서 기반 정보
  • Description List (dl) - 용어와 설명 구조

유형

List는 구조 유형에 따라 Unordered, Ordered, Description으로 나뉘며, 각 타입은 정보의 의미와 관계에 따라 선택합니다.

UL Unordered List

일반적인 정보 항목을 순서 없이 나열할 때 사용합니다.
설명 문단과 함께 보조 텍스트를 제공하며, 톤은 중립적이고 정보 전달 중심으로 구성합니다.

  • 일반적인 정보
  • 정보 항목 나열
  • 중립적이고 정보 전달 중심

ul.txt-list.dot>li*3

  • 계층적 하위 항목
  • 상위 항목 관련 부가 정보 전달
  • 가독성을 높이기 위해 계층 구조 명확히

ul.txt-list.dash>li*3

  • 중요한 항목이나 주목해야 할 정보 강조
  • 시각적 포인트 제공
  • 핵심 내용 빠르게 인지

ul.txt-list.star>li*3

  • 참고 자료나 외부 정보를 제공
  • 관련 링크, 문서, 규격
  • 참고 용도로 명확히 구분

ul.txt-list.ref>li*3

OL Ordered List

순서가 중요한 단계별 정보를 전달할 때 사용합니다.
단계별 작업이나 순서를 명확히 보여주고, 사용자에게 안내 목적을 분명하게 전달할 수 있습니다.

  1. 준비 작업 수행
  2. 데이터 수집 및 검증
  3. 최종 결과 검토 및 제출

ol.txt-list.num>li*3

DL Description List

용어와 설명을 짝지어 나열할 때 사용합니다.
각 용어에 대한 상세 정보를 명확하게 전달하며, 시맨틱 구조를 유지하여 접근성과 이해도를 높입니다.

접근성
웹 콘텐츠가 장애인이나 보조기기를 사용하는 사용자에게도 동일하게 이해되고 조작될 수 있도록 설계된 원칙과 방법.
시맨틱 구조
HTML 요소가 본래 의미에 맞게 사용되어, 스크린 리더와 검색 엔진 등에서 정보 구조를 명확히 전달할 수 있는 설계 방식.
UI / UX 일관성
동일 기능이나 요소는 사이트 전반에서 동일한 방식으로 표시 및 동작하도록 설계하여, 사용자가 혼란 없이 인터랙션할 수 있도록 보장하는 원칙.

dl.def-list>(div>dt+dd)*3

가이드라인

List 컴포넌트는 단순한 시각 요소가 아니라 정보 구조를 정의하는 UI입니다. 따라서 스타일보다 정보의 의미를 기준으로 선택해야 합니다.

동일한 리스트라도 목적에 따라 의미가 달라질 수 있으므로, 사용 시 항상 “왜 이 구조가 필요한가”를 먼저 판단해야 합니다.

권장 (Do)

정보 구조를 명확하게 전달하는 방향으로 사용합니다.

  • 정보 의미(순서 / 계층 / 그룹)에 따라 ul, ol, dl 선택
  • 한 페이지에서 리스트 타입 역할 일관성 유지
  • 텍스트 구조 단순화로 가독성 확보
  • 리스트 내부 항목은 동일 레벨 유지
  • 시각 스타일보다 의미 구조 우선

금지 (Don't)

리스트를 레이아웃 대체 수단으로 사용하지 않습니다.

  • 디자인 목적의 무분별한 ul/ol 사용
  • 버튼 / 카드 UI를 리스트로 강제 구성
  • dot / dash 스타일 혼용
  • 리스트를 grid 레이아웃처럼 사용
  • 의미 없는 중첩 구조 생성

디자인 원칙

  • 의미 우선 - 스타일보다 정보 구조
  • 일관성 - 동일 정보는 동일 구조
  • 명확성 - 구조는 단순하게 유지

접근성

List 컴포넌트는 HTML 시맨틱 구조를 기반으로 동작해야 하며, 스크린 리더에서도 동일한 정보 구조로 인식되어야 합니다.

시각적 스타일은 변경 가능하지만 정보 구조 자체는 변경되어서는 안 됩니다.

시맨틱 규칙

  • <ul> - 순서 없는 정보
  • <ol> - 순서 있는 단계 정보
  • <dl> - 용어 + 설명 구조

리스트 구조는 반드시 HTML 기본 요소를 사용해야 하며, div 기반 구현은 금지됩니다.

스크린 리더 동작

  • 리스트 진입 시 항목 개수 안내
  • ol은 순서 정보로 인식
  • dl은 용어-설명 구조로 읽힘

인터랙션 기준

  • 링크/버튼 포함 시 키보드 접근 가능해야 함
  • li 자체 클릭 이벤트 사용 지양
  • 포커스 순서는 DOM 구조를 따라야 함

주의 사항

  • div로 리스트 구조를 흉내 내지 않기
  • grid 용도로 ul 사용 금지
  • 시각적으로만 리스트처럼 보이게 만들지 않기
