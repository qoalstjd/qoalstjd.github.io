전체 페이지 구성은 홍보 → 정보 확인 → 예약으로 자연스럽게 이어지는 흐름을 목표로 했다. 방문자가 처음 접속했을 때 펜션의 분위기와 특징을 빠르게 인지하고, 필요한 정보를 확인한 뒤 예약까지 막힘없이 이어지도록 설계했다.

HTML, CSS, JavaScript 작업에 들어가기 전, 페이지 구조와 메뉴 체계를 먼저 정리했다. 구조를 먼저 정리해두면 이후 구현 과정에서 불필요한 수정과 고민을 줄일 수 있기 때문이다.

구조 설계

1. 전체 구조 방향

  • 메뉴 깊이는 최대 2Depth까지만 사용
  • 모든 서브 페이지는 해당 메뉴 하위에만 위치
  • 사용자가 현재 위치를 쉽게 인지할 수 있는 구조 유지

2. 메뉴 구조 정의

메뉴구조에 대한 표
Depth1 Depth2 설명
펜션정보 - 펜션 소개 및 기본 정보
객실정보 - 객실별 상세 정보
예약하기 - 예약 진행 페이지
고객서비스 공지사항 운영 관련 공지
새소식 이벤트 및 업데이트

3. 디렉터리 구조

메뉴 구조와 디렉터리 구조를 동일하게 맞췄다. 파일 경로만 봐도 어떤 페이지인지 바로 알 수 있도록 구성했다.


/pension
├─ about
├─ room
├─ book
└─ cs
    ├─ notice
    └─ news

UI · UX 설계

1. 설계 기준

  • 화려한 디자인보다 사용 흐름 우선
  • 한 화면에 너무 많은 정보 배치 지양
  • 처음 방문한 사용자 기준으로 구성

2. 사용자 행동 흐름

사용자가 별도의 설명 없이도 스크롤만으로 주요 정보를 자연스럽게 확인할 수 있도록 설계했다.

  1. 상단 이미지로 첫인상 전달
  2. 중간 영역에서 핵심 정보 확인
  3. 하단 또는 반복 영역에서 예약 버튼 노출

3. 화면 구성 기준

구성 순서 요소 목적
1 이미지 분위기 전달
2 정보 객실 및 이용 안내
3 행동 버튼 예약으로 유도

반응형 레이아웃

1. 반응형 설계 이유

  • 모바일 이용 비중이 높음
  • PC보다 모바일 환경 우선 고려

2. 모바일 기준 설계

  • 세로 스크롤 중심 레이아웃
  • 가로 스크롤 최소화
  • 한 손 조작 기준 버튼 배치

3. 레이아웃 분기 기준

구분 기준 화면 특징
Mobile 소형 화면 단일 컬럼 구조
Tablet 중간 화면 여백 및 배치 조정
PC 대형 화면 정보 확장 배치

4. 구현 방식

CSS 미디어쿼리 방식으로 해상도에 따라 반응하도록 설계

  • 정렬 위주는 flex 사용
  • 구조적인 레이아웃은 grid 사용
  • 공통 레이아웃은 재사용 가능하게 구성

이번 프로젝트를 통해 단순히 화면을 구현하는 것보다 구조와 사용자 흐름을 먼저 설계하고, 확장 가능성까지 고려하는 것의 중요성을 느꼈다.
