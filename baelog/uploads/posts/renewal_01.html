2. 정보 구조 및 사용자 흐름

기존 페이지가 정보를 보여주는 데 집중했다면, 리뉴얼 후에는 사용자의 행동 흐름을 자연스럽게 유도하는 구조에 초점을 맞췄다.

  • 기존
    • 정보가 한 페이지에 집중적으로 배치됨
    • 콘텐츠 간 중요도 구분이 명확하지 않음
    • 다음 행동으로 이어지는 흐름이 부족
  • 개선
    • 페이지 목적에 따라 콘텐츠를 명확히 분리
    • 스크롤 흐름을 고려한 단계적 정보 배치
    • CTA(이동·상세 보기) 위치를 명확히 정의

4. 구현 방식 및 기술 구조 변화

  • 기존
    • HTML / CSS 중심
    • 다중 페이지 구조
    • location.href 기반 페이지 이동
  • 개선
    • HTML / CSS / JavaScript
    • SPA(Single Page Application) 구조
    • history.pushState / replaceState 기반 화면 전환
    • 공통 컴포넌트 구조 분리

이번 리뉴얼은 단순한 디자인 변경이 아닌, 사용자 흐름을 기준으로 구조를 재설계하고 유지보수성과 확장성을 강화한 개선 작업이다.
